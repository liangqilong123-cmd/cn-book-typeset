# cn-book-typeset · 中文书籍 Markdown → 印刷级 DOCX

> **把一堆 Markdown 排成一本真的书**：标准 32 开、镜像边距、奇偶页分侧页眉页码、自动目录域、章节独立编页。
> 不是「Word 文档加个标题」，是按出版社的版式规矩排的。

[English](README.en.md) · 中文

## 为什么需要它

用 Word 手动排一本书，通常卡在这几处：

| 痛点 | 手动怎么做 | 这个工具怎么做 |
|---|---|---|
| 装订侧边距 | 每节手动设内外边距，改一次全乱 | `mirrorMargins` 一次开启，奇偶页自动镜像 |
| 页眉「奇数印章名、偶数印书名」 | 需要"奇偶页不同"+ 每章一个节 + 手工解链 | 每章自动建节，页眉随章变 |
| 页码贴在切口侧 | 奇右偶左要对齐，容易歪 | 页码域自动分侧，位置固定 |
| 目录页码 | 插入目录后忘按 F9，页码全错 | 插入 TOC 域，打开全选 F9 自动生成 |
| **正文里的真实手机号、邮箱** | 没人会逐页检查 | 自动脱敏 + 落盘前断言，漏一个就构建失败 |

最后一条是这个工具最特别的地方——详见 [脱敏与自检](#脱敏与自检)。

## 版式规格

默认标准 32 开（可改）：

| 项目 | 值 |
|---|---|
| 成品尺寸 | 147 × 210 mm |
| 页边距 | 上 20 / 下 18 / 内 20 / 外 16 mm（镜像） |
| 正文字体 | 宋体 五号（10.5pt），1.5 倍行距，首行缩进 2 字符 |
| 一级标题 | 黑体 16pt，另起一页 |
| 二级标题 | 黑体 13pt |
| 题词 / 引文 | 楷体，居中（出版惯例） |
| 页眉 | 9pt 灰字，下加细线 |
| 页码 | 9pt，奇数页右下 / 偶数页左下 |

## 快速开始

**不想装环境先看效果**：直接打开 [`examples/样张_32开_预览.docx`](examples/样张_32开_预览.docx)——那是用本工具排出来的成品，两篇古文、扉页、目录、分章页眉页码俱全。

```bash
pip install python-docx pyyaml

# 直接跑示例（两篇公版古文：桃花源记、岳阳楼记）
python build_book.py --config examples/book.yaml

# 只排第一章做样张
python build_book.py --config examples/book.yaml --sample
```

输出在 `examples/out/样张_32开.docx`。打开后 **Ctrl+A 再按 F9**，目录页码就生成了。

## 自己的书怎么用

1. 建一个目录，把章节写成 Markdown：

```
mybook/
├─ book.yaml
├─ 01_第一章.md
├─ 02_第二章.md
└─ img/
   └─ img_001.png
```

2. 写配置（照抄 `examples/book.yaml` 改）：

```yaml
book:
  title: 我 的 书 名
  subtitle: —— 副标题 ——
  running_head_even: 我 的 书 名      # 偶数页页眉
  running_head_odd_template: "{chapter}"   # 奇数页页眉（也可写 "{book} · {chapter}"）
  publisher_notes:
    - 本书仅供内部交流，不构成任何医疗建议。

chapters:
  - file: 01_第一章.md
  - file: 02_第二章.md

layout:
  body_size_pt: 10.5
  line_spacing: 1.5

pii:
  whitelist: ["13800001111"]     # 允许原样印出的号码

verify:
  must_contain: ["不构成任何医疗建议"]   # 成品里必须有这句，否则构建失败

output: out/我的书_32开.docx
```

3. 跑：`python build_book.py --config mybook/book.yaml`

**章节标题会从每个文件的一级标题自动读取**——不用在配置里再写一遍，也就不会出现「配置写第四章、正文其实是第五章」这种错位（作者在这上面栽过）。

## Markdown 支持范围

刻意做得很窄——书籍排版不需要复杂语法。

| 写法 | 效果 |
|---|---|
| `# 标题` | 一级标题，另起一页 |
| `## 标题` | 二级标题 |
| 普通段落 | 正文，首行缩进 2 字符 |
| `> 引用` | 正文段（去掉 `>`） |
| `- 列表项` | 正文段（加全角缩进） |
| `![图](img_005.png)` | 插图 + 图题「图 5」，图从 `image_dir` 找同名 `.png` |
| **短行**（≤14 字且无句末标点） | 自动判为题词，楷体居中 |

最后一条是这本书的实际需求：古籍里的诗诀、题识、单句警语，在正文里是独立短行，排成楷体居中才像书。

## 脱敏与自检

书稿里混着真实联系方式是常态——回忆录、家史、访谈整理尤其如此。这类东西一旦印进 PDF 就等于公开。

`pii_guard.py` 提供两层保护：

```python
from pii_guard import mask, audit

clean, n = mask(text, whitelist={'13800001111'})   # 手机/邮箱/座机/身份证 → 占位符
leaks = audit(clean, whitelist={'13800001111'})    # 再扫一遍
assert not leaks, f'仍含隐私信息：{leaks}'
```

构建流程里它被调了三次：

1. **正文解析时**逐行脱敏
2. **前置页文字**（书名、副标题、出版说明、页眉）同样脱敏——这些最容易被人忽略
3. **落盘前**对整个文档 XML 再扫一遍，发现漏网直接中止保存，不生成半成品

另外 `verify.must_contain` 会检查成品里是否还在规定的句子——用来防「免责声明被误删」。

```
✗ 必含内容缺失（可能是免责声明被删）：['不构成任何医疗建议']
```

## 已经踩过的坑（都修在代码里了）

这些不是理论，是实际排书时撞出来的：

1. **`add_section()` 会继承上一节的 `pgNumType`**——新建小节默认带 `start=1`，所以"续编页码"必须显式删除这个元素，否则每章页码都从 1 重来
2. **`mirrorMargins` 必须写进 `settings.xml`**，只设 `left_margin`/`right_margin` 不会变镜像
3. **奇偶页页眉要开 `odd_and_even_pages_header_footer`**，且每个节的 `even_page_header` 都要独立解链
4. **中文字体要设两次**：`run.font.name`（西文）+ `rFonts.set(qn('w:eastAsia'))`（中文），少一个就变宋体默认
5. **章名从正文一级标题取，不要手写**——手写版本曾把「第四部分」标成第五，四章连环错位
6. **首行缩进用 `Pt(size*2)` 而不是 `Cm(0.74)`**——字号一改，磅值跟着变，厘米是死的

## 局限

- **只输出 DOCX**，不直接出 PDF。DOCX → PDF 交给 Word / WPS / LibreOffice，保真度更好
- **目录需要手动按一次 F9**（Word 域机制决定，程序生成不了页码）
- **不含封面设计**，封面请在 Word 里做或另出图
- **不处理脚注、索引、交叉引用**——书籍排版里的这些请在成品 docx 上补
- **短行自动判题词的规则是启发式的**。想要精确控制，把题词单独放一个 `## 题识` 二级标题下即可
